## Feedback

- **A crafted control found a real hole, exactly as intended.** The first version
  checked only that recorded tiles held recorded values and that the arithmetic
  summed. The altered-coordinate control failed to be caught, revealing that
  chain *legality* was never validated — a chain rewritten to a different tile
  of the same value replayed clean, and on a board full of 64s that is most of
  them. `chainLegality()` exists only because the control was written to fail.
  Had I written the control to pass, the check would have shipped hollow.
- **Unexpected strength worth recording:** the recording is produced by the
  browser running `src/game.js`, while the replay runs `solver/engine.js` — two
  separate implementations that mirror each other. A clean replay is a
  cross-implementation agreement, not a self-check. That was not designed in; it
  was noticed while answering `gate-check`'s "reads own output?" question.
