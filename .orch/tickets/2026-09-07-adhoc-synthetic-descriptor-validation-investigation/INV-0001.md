## Cited findings

1. **High confidence — the prior half-score computation did not implement the
   user's stated descriptor.** The handoff defines half-score move as the first
   move reaching half of final points divided by the move budget. The selected
   scratch implementation divides by `game.chains.length`, which is moves used
   (`cheap-descriptors.js`, `computeCheap`). This differs whenever play ends
   before the budget.

3. **High confidence — the production descriptor module does not yet own
   either proposed axis.** `solver/behavior-descriptors.js` owns only the
   post-move `strandedCellPressure` registry. `solver/policy-eval.js` owns
   `meanChainLength` and `lateScoreShare` and hard-codes the production
   `chooseMove`. A synthetic validation can therefore stay experiment-local
   without changing the protected production policy or declaring a new
   MAP-Elites axis.

4. **High confidence — a cheap, explicitly approximate greed denominator
   exists.** `solver/engine.js#findGreedyChains` produces deterministic bounded
   paths from every non-blocked start tile and sorts them by immediate points.
   Legal prefixes of those paths can supply a wider controlled candidate
   range. The maximum over that pool is a beam-relative maximum, not the
   exhaustive legal-chain maximum used by the original human descriptor.

5. **High confidence — the two controls can be made structurally distinct.**
   A center parameter can shift the desired beam-relative capture ratio on
   every move, while a signed timing slope can redistribute the desired ratio
   from early to late around that center. A full factorial grid permits the
   realized axes to be checked for non-collapse instead of assuming the knobs
   worked.

6. **High confidence — experiment ordering is binding.**
   `experiments/README.md` and `solver/experiment-guard.js` require a complete,
   committed protocol with frozen source hashes before any generalizing run.
   The code harness must therefore land and be verified first; the successor
   research spec and protocol can then freeze its exact revision before
   controls or confirmation execute.

7. **High confidence — fresh identifiers are available at this revision.**
   `RESULT-0029` has no path or history, and neither `32,000,000` nor
   `33,000,000` appears in the tracked repository. The protocol must still add
   the chosen ranges to `experiments/SEEDS.md` when the run executes.

8. **High confidence — the live baseline is exactly the documented four-fail
   state.** `node --test solver/tests/*.test.js` at `9d125e8` reported 361
   tests, 357 pass, and the same four failures: two candidate receipt
   mismatches and two Universe Map staleness/generated-view failures. Runtime
   was 164.4 seconds. Regression comparison must use failure identity, not
   count.

## Contradictions

- The selected handoff calls the six descriptor definitions verbatim from the
  user, but its cited scratch computation implements a different denominator
  for half-score timing. The stated definition wins; the old computed timing
  values and joint-cell interpretation do not.
- The original greed ratio is exhaustive. The affordable candidate pool is
  beam-relative. A result from the latter cannot validate or rename itself as
  the former.

## Dead ends

- The production post-move descriptor registry cannot supply half-score timing
  because that measure needs the completed episode's final score.
- Sweeping only one chain-score percentile cannot independently exercise the
  timing axis; it would make half-score timing an uncontrolled byproduct.

## Gaps left uncovered

- No synthetic outcome data exists; no direction or effect size is known.
- The candidate pool may not realize the requested greed centers on every
  board. Pre-measurement controls must reject a collapsed grid.
- A positive beam-relative result would justify a separate exact-denominator
  study; it would not retroactively validate the original human greed ratio.
- Statistical thresholds and the final level/seed denominator must be frozen
  only after the code result supplies an exact runtime and source identity.
