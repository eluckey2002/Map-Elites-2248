### Proven cause with toggle evidence

The immediate cause is a false platform decision in the official installer: lines 870–873 decide whether the machine is Windows solely from the inherited process environment predicate `$env:OS -eq "Windows_NT"`. On this Windows host, `OS` is absent from the Codex/updater process environment even though the machine-scoped value is `Windows_NT` and .NET identifies the operating system as Windows x64.

The observed `powershell` command resolves to `C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe` version `10.0.26100.9278` (Windows PowerShell Desktop `5.1.26100.9278`). In that same host:

- baseline input: `EnvOS=`; `.NET RuntimeIsWindows=True`; the installer predicate emits the observed error and exits `1`;
- isolated toggle: set only `$env:OS="Windows_NT"` inside the probe; `.NET remains `RuntimeIsWindows=True`; the same predicate emits `PREDICATE_ACCEPT` and exits `0`.

This proves the predicate input is causal. No installer code was evaluated beyond the reproduced four-line guard, and no installation or configuration was changed.

### Deterministic reproduction

Fresh probe using the updater's resolved shell and the official source's exact predicate:

```powershell
powershell -NoProfile -NonInteractive -Command '
  "EnvOS=$env:OS"
  "RuntimeIsWindows=$([Runtime.InteropServices.RuntimeInformation]::IsOSPlatform([Runtime.InteropServices.OSPlatform]::Windows))"
  if ($env:OS -ne "Windows_NT") {
    Write-Error "install.ps1 supports Windows only. Use install.sh on macOS or Linux."
    exit 1
  }
  "PREDICATE_ACCEPT"
'
```

Observed: `EnvOS=`, `RuntimeIsWindows=True`, the platform-rejection error, `RejectExit=1`.

Toggle probe adds only `$env:OS="Windows_NT"` before the same predicate. Observed: `EnvOS=Windows_NT`, `RuntimeIsWindows=True`, `PREDICATE_ACCEPT`, `ToggleExit=0`.

Source evidence: official installer lines 870–873 contain the guard; line 875 begins the later 64-bit check. Fresh environment evidence: process `OS` empty, user `OS` empty, machine `OS=Windows_NT`, process `WINDIR` empty, runtime description `Microsoft Windows 10.0.26200`, runtime architecture `X64`.
