🎮 2248 Challenge - Bomb Defuse UAT Test

Test Objective: Verify that bomb tiles are properly defused (removed) when included in a merge chain.

📋 Quick Start

🎮 Open Game 📋 Copy Test Script

🔧 Manual Test Steps

Step 1: Open the Game

Click the "Open Game" button above or navigate to index.html

Step 2: Open Browser Console
  • Chrome/Edge: Press F12 or Cmd+Option+J (Mac) / Ctrl+Shift+J (Windows)
  • Firefox: Press F12 or Cmd+Option+K (Mac) / Ctrl+Shift+K (Windows)
  • Safari: Press Cmd+Option+C (you may need to enable Developer menu first)
Step 3: Run the Test Script

Copy and paste this code into the console:

// Unlock all levels localStorage.setItem('unlockedLevel', '50'); // Load level 40 game.loadLevel(40); // Wait for level to load, then inspect setTimeout(() => { console.log('=== Bomb Tile Inspection ==='); let bombsFound = []; for (let row = 0; row < game.grid.length; row++) { for (let col = 0; col < game.grid[row].length; col++) { const tile = game.grid[row][col]; if (tile && tile.isBomb) { bombsFound.push({ position: `[${row}, ${col}]`, timer: tile.bombTimer, value: tile.value }); console.log(`Bomb found at [${row}, ${col}], timer: ${tile.bombTimer}, value: ${tile.value}`); } } } console.log(`Total bombs found: ${bombsFound.length}`); }, 1000);
Step 4: Take Initial Screenshot

Capture the game showing level 40 with bomb tiles visible (look for 💣 icon)

Step 5: Test Bomb Defuse
  1. Identify a bomb tile on the grid (marked with 💣)
  2. Note its current timer value
  3. Create a merge chain that INCLUDES the bomb tile
  4. Complete the merge
  5. Expected Result: The bomb tile should be REMOVED from the grid (defused)
Step 6: Take After Screenshot

Capture the game after the merge to show the bomb has been removed

🧪 Advanced Testing

Test Scenario 1: Bomb NOT in merge chain
- Create a merge that does NOT include a bomb
- Expected: Bomb timer should decrease by 1
- Expected: Bomb should remain on grid
Test Scenario 2: Bomb IN merge chain
- Create a merge that INCLUDES a bomb
- Expected: Bomb should be REMOVED (defused)
- Expected: isBomb flag should be set to false

📊 Expected Console Output

Bomb found at [X, Y], timer: N, value: M Total bombs found: Z // After merging a bomb: // The tile at that position should either be: // 1. Removed completely (null) // 2. Have isBomb = false

📸 Required Screenshots

  1. Initial game state showing level 40
  2. Console output showing bomb positions
  3. Before merge: Grid showing bomb tile with timer
  4. After merge: Grid showing bomb has been removed/defused

✅ Pass/Fail Criteria

PASS: Bomb tile is removed from grid after being included in a merge
FAIL: Bomb remains on grid after merge (only timer decreases)
