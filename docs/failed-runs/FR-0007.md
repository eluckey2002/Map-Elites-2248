# FR-0007 — LC-0009 classified partial-route value links by live-prefix length

**Occurred:** 2026-09-28

**Run:** `LC-0009-REPORTABLE-1`

**Stage:** closeout, after raw persistence and before the result was committed

## Observed failure

The retained move-9 champion timeline reported three missing value-order links
that were actually valid doubles: `P024` 128 to `P031` 256 before
continuations 1 and 2, and `S017` 64 to `P024` 128 before continuation 3. The
run therefore cannot answer the frozen request for exact earlier missing nodes
and links, and its closure is `INVALID` with no primary outcome.

## Root cause

The assessor filtered absent inputs out of the route prefix before calling the
engine's incremental chain helper. When earlier inputs were absent, a later
pair could become the apparent second step; the helper then required equality
even though the pair's frozen route position allowed equality or doubling.

## Prevention

The successor assessor checks each present consecutive pair by its original
frozen route index: equality only for the first pair, then equality or exactly
double for every later pair. Its focused test removes an earlier node from an
`8-8-16` route and proves the still-present `8-16` pair is not falsely named as
a value-order defect before any reportable successor run.

The retained LC-0009 raw, recomputation, and invalid closure remain preserved
as the evidence for this failure.
