# FR-0008 — LC-0016 full-board path search exceeded the diagnostic budget

**Occurred:** 2026-09-30

**Run:** `LC-0016-FIRST-CARRIER-PATH-EXHAUSTIVE`

**Stage:** execution, before a result artifact was retained

## Observed failure

The initial implementation searched every simple legal chain from every tile
after every retained continuation action. It did not finish within the normal
30-second focused-check window on the retained boards, so it produced no
reportable artifact or outcome.

## Root cause

The implementation broadened the question from an observed replay event to a
full hypothetical board search. The accepted bounded question is when the
tracked survivor descendant actually re-enters a chain the retained replay
executes; that requires lineage replay, not enumeration of every possible
path.

## Prevention

`tools/diagnose-lc0016-first-carrier-path.js` now tracks the survivor lineage
through the exact retained continuation and records only its first later chain
input. `solver/tests/lc0016FirstCarrierPath.test.js` replays all seven selected
pairs, checks the retained artifact exactly, and pins the known Level 54 cash
re-entry at continuation move 5. This keeps future versions inside the stated
question and catches replay drift before a result is retained.
