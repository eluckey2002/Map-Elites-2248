# Play observation template

Use this after an interesting human play. It is a lightweight memory aid, not
an experiment form. Capture what made the board matter before trying to turn
it into a general rule.

```md
## EO-YYYY — short plain-language title

**Level / board:**
**Seed or session:**
**Remaining moves when it became interesting:**
**Screenshot / replay:**

**What happened:**

**What I did and why:**

**What alternative was available:**

**What changed the plan:**

**Outcome:**

**What I think this means:**

**What it does not establish:**

**Useful next capture:**
```

### Per-turn build notes (use when building toward a high-value harvest)

| Turn / moves left | Total board value | 256s held | Higher tiles held | What I deliberately did **not** take | Gravity route I am setting up | What changed after the move |
| --- | ---: | ---: | --- | --- | --- | --- |
| | | | | | | |

**Total board value** means the sum of live tile values currently on the
board. It is a material measure, not a complete strategy measure: two boards
can hold the same value while only one has its 256s dense and connected enough
to build a 4K. Note where the 256s are or attach a screenshot when their
placement is the point.

For a build-and-harvest play, also note each important chain's input values,
chain length, bonus, resulting tile, and whether it used a tile built earlier.
For a 512 or bomb event, note whether a spare 512 existed, where the bomb was,
the move cost of rebuilding, and the endgame route chosen.
