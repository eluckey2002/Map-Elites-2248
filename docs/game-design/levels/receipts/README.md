# Archetype work receipts

These are byte-preserving snapshots of the local operational receipts from the
Connections/Delivery design work. Filenames are the original task IDs. They
retain their original dates, local paths, commands, results and limitations;
they do not assert that historical tests were rerun at release time.

The originals remain in the local Blackboard runtime. Prior append-only
playtest entries may still cite those original paths. This directory supplies
their durable counterparts without rewriting the historical entries.

The frozen Keep a Line analysis input is included for its exact-board analysis.
Ongoing session directories, the Blackboard database, machine-local backups
and future plays are not published here. Local archive references in receipts
still require the same-machine preservation files.

Start with [the current integration record](../connections-integration.md),
[the build receipt](CONNECTIONS-LEVELS-BUILD-1.md), and
[the handoff receipt](CONNECTIONS-LEVELS-HANDOFF-1.md).
Independent review, native QA and owner acceptance are distinct from automated
verification; read each receipt's completion boundary.
